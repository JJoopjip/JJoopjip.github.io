Job Board

Job hunting starts with too many postings and too little time. This board gathers the ones that reach me, grades each against my own experience, and shows a short “why”, so I spend my effort on the roles worth applying to.

Built with Python · Claude grading Runs privately on my machine Feeds the Résumé Generator
01CollectAlert emails + public job boards
02Pre-filterAge, seniority, duplicates
03Grade A to FAgainst a written rubric
04I reviewOn my phone, with filters
05Hand offTo the résumé generator
Live demo

The real board runs privately on my machine, so I rebuilt its interface here. Every company and posting is a made-up mock-up. None are real employers or real listings, and none come from my own search. Try the filters, open an analysis, and mark a job as interested.

One question: how likely is this to lead to an interview?

AStrong match: apply
BGood match: apply (B- or better)
CPartial or stretch
D / FWeak or off-target: skip

Claude grades each posting against a written rubric and my real experience, never an invented one. Skills match is the main driver. Seniority counts in both directions: a role far above or far below my level loses points. Health, pharma and medtech employers earn a bonus. Postings that only show a title are graded too, but tagged so the weaker evidence is visible. A hard blocker, such as a required security clearance, moves a job to an Excluded tab with the reason.

Every grade shows its why

Level, skills and domain each get one short line, so a B+ is never a black box, and I can disagree with it.

Newest and best on top

Sort by best match, newest or grade; filter by market, verdict and status. Old postings drop off on their own.

It never applies for me

The board sends nothing and submits nothing. I read each analysis, decide, and submit every application myself.

Mianmian & Rourou

Two original characters, Mianmian (a pink chibi bearcat) and Rourou (her raccoon partner), designed and shipped as animated sticker packs for chat apps. I run the whole thing: character design, AI production, packing to each platform's limits, and store submission.

One character bible, one generation, every platform. Characters are locked to a written spec and palette, each animation is generated once and packed for every store, and every clip is checked for frozen motion and extra limbs before it ships.

Built with Python · DeepInfra (FLUX, Pixverse) Formats animated WebP · APNG Characters original, mine

Still images of the characters. Hover or tap a sticker to make it move. Animation previews are coming soon.

The same character, every pose

Each character has a written spec and a fixed colour palette. New poses are edited from approved reference art rather than generated from scratch, so Mianmian and Rourou stay recognisable across a whole pack.

Generate once, pack for every store

Animation calls cost money, so each sticker is generated once and the same frames are packed for every platform. The frame count is chosen up front so it clears every platform's file-size cap.

Checked before it ships

The model can return a near-static clip or add an extra limb. Every animation is composited onto a solid background and inspected before packing. Frame counts alone don't catch it.

Found a silent failure

One API route quietly dropped reference images while still billing for the call. I documented it, moved every call to the route that honours references, and wrote down how to verify it with and without references.

How it's made

The characters are mine. The first reference art was generated with Gemini; later poses and animations use image and video models on DeepInfra, directed and reviewed by me. Each platform has its own format and size limits, so packing is scripted per platform. A Mianmian + Rourou couple pack is planned but not started.
