Project 01

AI Résumé Generator

Paste a job posting and get a one-page résumé built from my real career history — plus, if I want, a matching cover letter and a coverage score that shows exactly how well I fit the role.

What makes it different

An autonomous Claude agent — not a chatbot wrapper. It runs headless with no chat window: reads my career file, writes the draft, renders the PDF, and re-runs itself until it fits one page — zero human touch from posting to finished document.

Live demo

The real generator runs locally and drives a headless Claude agent that writes from my private career history, so I rebuilt its interface here. Press Generate to watch a real run replay — the log lines are the ones the actual pipeline prints. Nothing you type is sent anywhere.

Flexible output

Résumé, cover letter, or both

Choose résumé only, résumé and cover letter in one run, or add the cover letter afterward once the résumé looks right.

Coverage score

Know your fit before you apply

Each run analyses how well the résumé matches the posting, so I can see where the gaps are and decide whether — and how — to close them. Gaps get closed by adding real experience, never by inventing it.

Live step log

Nothing hidden

A running log shows each step as it reads the spec, my history, and the posting, then writes and renders the documents.

One-click hand-off

Straight to the tracker

Send the finished résumé, cover letter, and posting to the Application Tracker in a single click — no copy-paste.

Under the hood

Not a chatbot wrapper.

Most AI résumé tools

Paste your résumé into a chat window, copy the answer back out, and hope it fits the page.

This one

Claude (Anthropic) runs headless as an autonomous agent — no chat window. It reads my career file, writes the draft, renders the PDF, measures the page, and re-runs itself until everything fits on one page. Between “paste posting” and “finished PDF”, no human touches it.

How it connects

This is the source of truth for both tools. When I add an application to the tracker, it pulls from here — so the résumé, cover letter, and posting live in one place and never get duplicated. See the Application Tracker →
